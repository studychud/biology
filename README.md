# The Human Digestive System: Study Guide

A study site for the digestion unit. It has two sections:

- **Learn**: the path food takes, mechanical vs. chemical digestion, a labeled diagram of the whole system, and every organ's structure, function, mechanical digestion, chemical digestion, and other facts. Includes a side view of the mouth and throat (teeth, tongue, salivary glands, epiglottis, larynx, trachea, esophagus), a villus diagram, enzymes and chemicals, and key words.
- **Practice test**: multiple-choice and diagram questions with instant feedback and a review of missed questions.

The anatomy drawings are adapted from Mariana Ruiz's public-domain [digestive system diagram](https://commons.wikimedia.org/wiki/File:Digestive_system_diagram_en.svg) on Wikimedia Commons.

It's a single self-contained `index.html`. Open it in any browser, or publish it with GitHub Pages (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).
